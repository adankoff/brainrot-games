The project is a game studio that reskins classic casual games with brainrot/meme themes (Italian Brainrot, Skibidi Toilet, etc.). Tech stack is HTML5 Canvas + vanilla JavaScript. Target audience is Gen Z/Gen Alpha meme consumers.

**Why:** The meme-to-market pipeline is now formalized in mobile gaming (Steal a Brainrot hit 20M CCU on Roblox in 2025). The studio needs simple mechanics that accept rapid theme swaps as memes cycle.

**How to apply:** All research and recommendations should prioritize implementation speed, reskin flexibility, and ad-based monetization. The studio's competitive advantage is speed of cultural response, not technical depth.
